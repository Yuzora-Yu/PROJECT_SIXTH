# 現実予測の公開状態

2026-09-15: ユーザー指示により現実予測を「開発中」に戻しました。

- 正本は shared/config.js の predictionsEnabled。現在は false。
- メニューからは開発中の案内を表示し、予測一覧の取得・再取得や投票操作は行いません。
- Worker は /api/predictions とその配下を 409 で停止します。通常の接続時の予測精算も停止します。
- 既存の予測、投票、残高、観測記録は削除しません。デイリー、訓練、キャラクター、戦闘等は継続します。
- publish-predictions.yml の定期実行を停止しています。手動ワークフローは保守用に残していますが、公開再開はユーザーの指示後に判断します。
- APIテストだけは依存注入で有効状態も検証し、既存の投票・精算ロジックの回帰テストを維持します。この切替はHTTPから指定できません。

再開時は、データの有効性、受付期限、未精算記録、公開ワークフローを確認したうえで、UI/APIを同時に切り替えてください。
