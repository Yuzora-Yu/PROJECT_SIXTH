# Reality Prediction — 情報源ポリシー

確認日: 2026-09-04

## 目的

予言問題を「面白い」だけでなく、締切前には未確定で、締切後には誰でも検証できる形にする。

情報源の原則は次の順序。

1. 大会・リーグ・政府・統計機関・主催団体などの一次公式情報
2. 同じ結果を別経路で確認できる準一次情報
3. Reuters / AP 等は発見とクロスチェック
4. 一般ニュース、まとめ、SNS は原則として最終 result source にしない

初期マスターは `ops/PROJECT_SIXTH_GeminiSpark_Prediction_Ops.xlsx` の `07_SOURCE_MASTER` を正とする。

## 初期優先カテゴリ

### スポーツ

最初は最も安定しやすい。

- NPB
- Jリーグ
- B.LEAGUE
- MLB
- Formula 1
- FIFA
- ATP
- NBA
- NFL
- NHL

「試合結果」「優勝者」「順位」等で、公式結果ページが固定できるものを優先する。延期・中止・没収試合等の扱いを `resolution_rule` に書く。

### 経済

- 日本銀行 外国為替市況
- 総務省統計局 CPI
- 内閣府 GDP
- JPX 指数
- 財務省 貿易統計
- Federal Reserve H.10
- BLS CPI
- BEA GDP

速報・改定・終値・時点値を混同しない。

例: 月末 USD/JPY 問題なら「暦月末」ではなく、「当月最終営業日に日銀が公表する17時時点のドル/円スポット中心相場」など、採用系列と時点を固定する。休日や公表訂正時の扱いもルール化する。

### エンタメ・芸術・学術

- Billboard JAPAN
- ORICON
- Oscars
- GRAMMY
- Nobel Prize
- Booker Prize
- Cannes
- Venice / La Biennale
- Emmys

ランキングは全文転載せず、ゲームの判定に必要な事実だけを保持する。各サイトの利用条件・著作権表示に従う。

### 科学・宇宙

- JAXA
- NASA

打上げ予定は `EVENT_WATCH` に適する。結果判定は個別ミッションページや公式プレスリリースを指定する。

### 政治・公的発表

- 首相官邸等の政府一次情報
- 選挙は各選挙管理機関等の公式確定結果を候補化

政治問題は「評価」ではなく客観的に一意判定できる事実だけを採用する。刺激的な見出しを優先しない。

## 新規 source の昇格

T01/T02 は `PROPOSED` まで。

T03 が確認する項目:

- 公式運営者は誰か
- URL が恒常的か
- ログインなしで誰でも確認できるか
- paywall があるか
- 結果確定を一意に判断できるか
- 更新日時 / 訂正履歴を確認できるか
- robots / browser access で Spark が安定して開けるか

T04 は T03 の根拠を読み、採用するなら source_id を発行して MASTER へ昇格する。

## ACTIVE / PROBATION

`ACTIVE`: 現時点で主力利用可。  
`PROBATION`: 公式性は高いが、表示安定性、URL、結果ページ粒度などを運用で再確認する。  
`DEPRECATED`: 新規問題では使わない。  
`BLOCKED`: 信頼性・アクセス・利用条件等の理由で使用禁止。

## 災害・危機・死亡等

公的データ源として存在していても、重大災害・死亡・負傷規模等を「当てる娯楽」として扱わない。情報源の存在と、予言問題として適切かは別判断とする。
