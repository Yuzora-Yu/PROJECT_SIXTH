# 実装ノート — 2026-09-04

## 位置づけ

### 粒子v2時点のフィードバック（改訂履歴）

粒子のタップ/クリック判定半径を26から36 logical px（約1.38倍）へ拡大。Dailyと訓練の共通判定へ反映。粒子ルールv2として保存し、v1で開始済みの試験は従来の判定を維持する。訓練の自己ベストと平均もルールバージョンごとに分ける。

v0.3.0 / MVP。Vanilla JS ES Modules + Canvas + Workers / D1。ブランチは `yuzora/mvp-foundation`。
ユーザー指定リポジトリ・既存の配信方式を維持するため、別のSitesプロジェクトや別フレームワークへ移行していません。

## 保存とセキュリティ

- Cookieには256-bitランダムトークン、DBにはSHA-256ハッシュのみを保存。HTTPSではSecureを付ける。
- mutationはsame-origin、専用ヘッダー、JSONサイズ上限、型・所有チェックを行う。
- D1 `players` のrevision比較更新と `operations` の冪等レシートを同一batchで保存。競合時は409、同じキーの再送は既存結果を返す。
- カードの未回答正解はbootstrap、start、playerに含めない。粒子の結果はサーバーで座標・時刻から再計算。
- 途中離脱と低FPSは結果を破棄して再挑戦可能。クライアントを解析する上級者への完全なアンチチートではない。
- Dailyは同日/testの完了を保持、04:00跨ぎの古い未完attemptは失効。Trainingはサーバー報酬APIを呼ばない。
- 戦闘回数は開始時に消費。結果はサーバーが生成し、finishはその結果だけを精算。画面を閉じてもロビーから再開できる。
- 予測/レイドのAPI、AIキー、ユーザーアクセス時AI呼び出しは存在しない。
- ゲストの大量作成に対する本番レート制限、運用バックアップ方針、ログ保持期限の設計は運用上の残課題。
- プレイヤーごとのJSONは簡潔な初期設計。長期運用では履歴を別テーブルへ移行しページングする必要がある。

## 占術と分析

初期研究値は全軸15、XPから単調増加し上限100。日次コンディションは当日XPから0〜10に制限。
キャラ適性は独立した新作オリジナル値。数秘は全出生数字の桁和で、途中の11・22・33を残す方式。娯楽用5軸と短い所見は固定ルールであり能力診断ではない。
惑星の位置はAstronomy Engine 2.1.19を使い、地心の黄道座標・トロピカル方式で計算。出生時刻とUTC差を指定可能。時刻不明では現地正午を代表値とし、日内の星座候補を併記する。月のアスペクトは時刻不明時に省く。出生地座標を収集しないためASC・ハウスは未実装。
出生情報と任意MBTIはlocalStorageだけに保存し削除可能。出生日時を送信しないことをブラウザテストで確認。初期値反映時には数秘・タイプ・星座区分を計算用に送り、補正値だけを保存する。MBTIは既存結果の自己申告であり新しい診断は行わない。

## 記録・共有・配信

- 訓練終了イベントで一覧を即時再描画。試験ごとに直近30件、過去最高はルールバージョン別に保存。観測記録ではDaily・訓練を併記し、粒子訓練にも再生を用意。
- 研究記録・数秘・総合プロフィールに研究員口調の所見と共有ボタン。幅1080pxのPNGを端末内生成、X投稿画面と標準共有に対応。出生日時・被験者IDは共有画像に含めない。Xへの自動送信・画像自動アップロードは行わない。
- 配信先は `https://yu-zora.com/project_sixth/`。専用Workerと専用D1を作成し、パス単位で接続。スラッシュなしは308、API・素材の相対パスとCookie Pathをサブフォルダへ対応。
- GitHub PagesではAPIを実行できないため利用しない。GitHub Actionsは検証のみ、本番反映は `npm run deploy`。

## v0.3.0 — 共鳴プロフィールと研究記録

- 共有画像は「数秘＋レーダー」「総合プロフィール」「研究記録」の3種類。総合版は数秘・MBTI日本語名・レーダー・10天体・所見を集約。研究記録版は名前・ゲーム内研究値・Daily成績・研究開始日・総研究日数を表示する。画像内に補足注釈は置かない。
- 数秘を12種類の基礎ベクトルとして定義。MBTI4指標の補正と、10天体の四元素の重みを加え、20〜100に制限。出生時刻不明で星座が複数候補となる天体は補正から省く。
- 数秘12種×MBTI4グループの48の組合せ文、16タイプ固有の所見、四元素、太陽と月の16関係・太陽の3区分、水星と判断軸、各数秘の見落としやすい場面を使って所見を組み立てる。一般的なMBTI日本語通称は16Personalitiesの表記を参照し、所見とゲーム計算は本作独自。新しい心理検査の妥当性は主張しない。
- 5軸ごとの最終プロフィール値の10%を研究初期値15へ加算（例: 72なら15+7.2）。研究XPからの成長は別加算。更新で加算履歴を積み増さず補正を置き換え、解除も可能。未入力でもプレイ可能。
- 誕生日は既存キャラ適性を維持したまま、元の年齢を2026-09-04時点の年齢とみなした1年分の候補から旧プロフィール式との二乗誤差が最小の月日を選定。同点は候補日順。元年齢不明の人物は2000年を創作用の検索基準に使用。内部計算用の年・誤差はCHARACTER_BIRTHDAYS.jsonに記録し、配信カタログには月日だけを収録。公式設定への変更ではない。
- 名前付き仲間・特別キャラのID 1000未満を30枠収録。村人や敵NPCのマスタは仲間枠に含めない。ルーナは元マスタの2時期を別枠で保持。403の画像は401_past5y_normalからコピー。未取得は一覧・詳細ともシルエット。
- 初期選択は6人から一度。既存プレイヤーも1回選べ、所持・育成・RCは保持。新規の仮ジョセフが未育成なら、別の初期キャラ選択時に入れ替える。アルスの職業は本作側だけ冒険者。
- 粒子ルールv3: 30秒、半径72 logical px、5種類16イベント。指の範囲にある有効な異常を、近くの正常粒子より優先して採点。入力円を短時間表示。v1/v2の過去記録は元の60秒・判定で再生する。
- 潜在法則の新規受付・UIを終了。過去XPは保持し、現在の研究レポートはカードと粒子を対象とする。Daily上限20 RC、戦闘込み70 RC。
- ユニット・API検証27件、Edgeの4シナリオ。APIの二重加算防止、入力不正、旧記録、初期選択、名前、画像3種、スマホ幅を確認。
